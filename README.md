> Modern, high-performance portfolio engineered with vanilla CSS, modular JavaScript, dark-mode aesthetics, dynamic Framer-fidelity spring physics, and organic radial lighting.

## 🚀 Overview

Personal developer portfolio for **Vikas Rai**, Senior Full Stack Developer & System Architect with extensive domain mastery across Commercial Insurance, FinTech, Real-Time Tracking, and Distributed Systems.

- **Design Aesthetic**: Inspired by high-end Framer templates (DevSync) with Space Grotesk typography, neon emerald accents (`#7AF298`), and deep slate matte backgrounds (`#0B0D0E`).

- **Key Features**:
  - Interactive Project Showcase & Dynamic Filters
  - Accordion Service Cards with Interactive Hover Physics
  - Process & System Architecture Workflow Steps
  - Microservices & Technical Competencies Breakdown
  - Responsive Navigation with Animated Drawer
  - Magnetic Cursor & Radial Mouse Spotlights

## 📦 Local Development

To run locally:

```bash
# Clone the repository
git clone https://github.com/VirtualRV/MyPortFolio.git

# Navigate to the project directory
cd MyPortFolio

# Serve with any static server (e.g. npx serve, python http.server, or Live Server)
npx serve .
```

Visit `http://localhost:3000` in your browser.
